Marissa Elisabeth Ellin --- Personal Portfolio

Portofolio personal Marissa Elisabeth Ellin, mahasiswi Sistem dan
Teknologi Informasi, yang mendokumentasikan proyek, proses
pembelajaran, sertifikasi, pengalaman, eksplorasi teknologi, dan
refleksi pengembangan diri.

Tentang Proyek

Website Portfolio Marissa adalah website portofolio personal yang
dirancang sebagai arsip terbuka untuk mendokumentasikan perjalanan
akademik dan karya Marissa Elisabeth Ellin sebagai mahasiswi Sistem dan
Teknologi Informasi.

Website ini tidak hanya menampilkan hasil akhir proyek, tetapi juga
memberikan konteks mengenai peran, proses pengerjaan, teknologi yang
digunakan, tantangan, hasil, dan pembelajaran dari setiap karya.

Tujuan

Website ini dibuat untuk:

memperkenalkan profil dan bidang minat akademik;

mendokumentasikan proyek dan studi kasus secara terstruktur;

menampilkan sertifikasi dan pengalaman yang relevan;

menunjukkan perkembangan kemampuan dari waktu ke waktu;

menjadi arsip pembelajaran yang dapat diperbarui;

menyediakan kanal komunikasi untuk diskusi proyek dan kolaborasi
akademik.

Fitur Utama

Hero & Personal Branding

Bagian pembuka memperkenalkan identitas, bidang studi, fokus eksplorasi,
serta ajakan untuk melihat proyek dan terhubung.

Tentang Diri

Menjelaskan pendekatan belajar, prinsip kerja, kebiasaan belajar, dan
nilai yang digunakan dalam proses pengembangan diri.

Proyek & Studi Kasus

Proyek dapat dicari dan difilter berdasarkan kategori. Setiap proyek
mendokumentasikan gambaran umum, tujuan, peran, proses, teknologi,
tantangan, hasil, pembelajaran, dan bukti proyek.

Proyek yang terdokumentasi antara lain:

Website Dinamis Sekolah Minggu Gereja Yesus Sejati Pontianak ---
sistem berbasis PHP & MySQL dengan halaman publik dan panel admin.

Desain UI/UX Aplikasi "Geprek Momo" --- studi kasus digitalisasi
pemesanan UMKM kuliner menggunakan Figma dan usability testing.

Onboarding Buddy System --- eksperimen agen AI berbasis Langflow
dengan arsitektur RAG, Astra DB, embedding, dan model bahasa.

Desain Konten Edukatif & Kampanye Visual Media Sosial --- karya
visual menggunakan Canva, copywriting, dan visual storytelling.

Sertifikasi, Pengalaman, Fokus Belajar & Refleksi

Website menyediakan bagian khusus untuk sertifikasi, pengalaman, fokus
pembelajaran, dan refleksi perkembangan diri.

Dukungan Bahasa

Pengguna dapat berpindah antara Bahasa Indonesia (ID) dan English
(EN).

Responsive Design

Antarmuka dirancang untuk desktop dan perangkat mobile, termasuk
navigasi mobile drawer.

Interaksi Dinamis

JavaScript menangani pergantian bahasa, pencarian dan filter proyek,
filter sertifikasi, modal studi kasus, navigasi mobile, tombol kembali
ke atas, tombol WhatsApp, dan penyalinan email.

Teknologi

Teknologi                           Penggunaan

HTML5                               Struktur dan semantik halaman

CSS3                                Styling, layout, responsive design,
dan visual system

Tailwind CSS                        Utility-based styling dan
responsive utilities

JavaScript (Vanilla)                Interaksi, rendering konten
dinamis, filter, modal, dan state

Google Fonts                        Tipografi editorial dan handwriting

LocalStorage                        Menyimpan pilihan bahasa pengguna

Website menggunakan pendekatan HTML, CSS, dan JavaScript tanpa
framework frontend besar, dengan konten portofolio yang dikelola
melalui JavaScript.

Cara Menjalankan

Membuka langsung

Buka index.html menggunakan browser.

Menggunakan Live Server

Jika menggunakan Visual Studio Code:

buka folder repository;

install ekstensi Live Server;

klik kanan index.html;

pilih Open with Live Server.

Catatan Konfigurasi

Sebelum dipublikasikan, sesuaikan placeholder seperti:

YOUR_WHATSAPP_NUMBER

Pastikan seluruh aset pada folder gambar/ memiliki nama dan path yang
sesuai dengan referensi pada index.html atau script.js.
